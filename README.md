# CraftControl Issues

This repository is the public place to report bugs and request features for CraftControl.
It contains no source code.

- Found a bug? [Open a bug report](../../issues/new?template=bug_report.yml)
- Have an idea? [Request a feature](../../issues/new?template=feature_request.yml)

Please search existing issues before opening a new one, and do not post passwords, tokens or other secrets.
